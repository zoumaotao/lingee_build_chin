3.2 场景详述 — 工单全链路

用户在灵基问询 → 智能体答案未解决 → 自动触发提交工单 → 后台自动分配工单 → 通知推送给处理人 → 处理人在灵基处理 → 回复送达提问人 → 提问人评价打分 → 推送后台记录

核心要求：

  • 后台分配工单后，需通过 MCP Server 向处理人推送工单消息（自定义格式）
  • 处理人的回复需通过灵基实时送达提问人
  • 提问人的评价打分结果需回传后台系统记录
  • 整个链路中，用户和处理人均不离开灵基
